# Изменения PS Filter

## 1.1.2 (11.11.2026)
- OpenCart 3.0.5.x: панель фильтра выводится (ядро 3.0.5 не находило вложенные шаблоны фасетов, панель была пустой).
- Кеш: выборки с произвольными границами цены и результаты поиска не записываются в базу, у таблицы кеша есть предел — перебором адресов ее больше не раздуть.
- Выдача: не больше 1000 товаров на страницу, страница за последней — без лишнего запроса к базе.
- Настройки: ключ cron меняется только кнопкой «Новый ключ», служебные значения через сохранение настроек не меняются; ключ cron виден только тем, у кого есть право на изменение.

## 1.1.1 (10.11.2026)
- В OpenCart 4 посадочные страницы фильтра попадают в карту сайта модуля PS Sitemap, как и в OpenCart 3.
- Название и описание расширения в OpenCart 4 — на английском (одна строка для всех языков админки).
- Подсказки в админке и описание модуля написаны без названий сторонних сборок и сайтов.
- В шаблоне админки OpenCart 4 галочки со своим классом больше не теряют его.
- README на английском и русском.

## 1.1.0 (10.11.2026)
- Версия для OpenCart 4.1.0.4: архив ps_filter.ocmod.zip ставится через «Расширения → Установщик», проверено на PHP 8.5.
- В OpenCart 4 обновление через удаление и новую установку сохраняет фасеты, посадочные страницы, индекс, настройки и место панели в макетах (настройка «При удалении модуля сохранять данные»).
- Поиск по каталогу вместе с модулем PS Search работает и в OpenCart 4.
- Тексты модуля пишутся через «е» (правило студии).

## 1.0.1 (09.11.2026)
- Подсказка к настройке «Фасеты — только по товарам в наличии» переписана: без сравнения с другими модулями.

## 1.0.0 (09.11.2026)
- Название в админке — «PS Filter: фильтр товаров».
- Пункт «PS Filter» теперь внутри меню «Каталог», подпункты (Настройки, Фасеты, Посадочные, SEO-шаблоны, Индексация) — на следующем уровне. Пока модуль выключен, пункта в меню нет.
- На странице настроек — вкладка «Поддержка»: версия, что нового, связь со студией, сведения о сайте для письма в поддержку.
- Внизу всех страниц модуля — строка с версией и адресом поддержки.
- Лицензия MIT.

## 0.7.9 (07.11.2026)
- Посадочные страницы фильтра попадают в карту сайта модуля PS Sitemap отдельными файлами.

## 0.7.8 (07.11.2026)
- На телефоне раздел больше не прыгает при загрузке: панель фильтра сразу убирается в шторку и не занимает место над товарами.

## 0.7.7 (29.10.2026)
- Новая настройка «Не индексировать фильтр, равный разделу» (включена): если выбор в фильтре не сужает раздел, страница закрыта от индекса, ведет на раздел и не попадает в автостраницы и карту сайта.

## 0.7.6 (28.10.2026)
- Новая настройка: выдача раздела без фильтра показывает все товары, а с фильтром — только те, что в наличии.
- Новая настройка: значения характеристик с заглавной буквы («для волос» → «Для волос»).

## 0.7.5 (28.10.2026)
- Автоподбор фасетов на странице производителя и в поиске учитывает фасеты, заданные для всех разделов.
- Новая настройка: разделы, товары которых не показываются на странице производителя (например, запчасти).

## 0.7.4 (22.10.2026)
- Совместимость с PHP 8.4 без предупреждений в журнале.

## 0.7.3 (18.10.2026)
- Значения, которые различаются только точками над «е», больше не дают предупреждений в журнале ошибок.

## 0.7.2 (17.10.2026)
- Группировка товаров работает и на странице раздела без фильтра; группы пересчитываются при смене артикула или модели.
- Закрытая шторка фильтра не попадает в переход по Tab; выбранный пункт не прячется под липкой шапкой.
- Продажи для сортировки «Популярные» пересчитываются ночью, а не при первом заходе покупателя.

## 0.7.1 (16.10.2026)

## 0.7.0 (15.10.2026)
