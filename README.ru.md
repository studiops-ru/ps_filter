# PS Filter: фильтр товаров

Бесплатный модуль с открытым кодом (MIT). Фильтр товаров для разделов, страниц производителя и поиска:
фасеты по цене, производителю, характеристикам, опциям, наличию и своим полям, выдача без перезагрузки,
счетчики товаров у каждого значения, мобильная шторка, посадочные страницы фильтра с ЧПУ и SEO-шаблоны,
карта сайта посадочных. Работает на своем индексе в базе: быстро и на каталогах в десятки тысяч товаров,
для очень больших каталогов можно подключить поисковый сервер Manticore.

## Что делает

- **Фасеты:** цена (ползунок и поля), производитель, характеристики, опции, наличие, акции, свои фасеты товара.
  Значения со счетчиками; недоступные — скрыты или серым, на выбор. Автоподбор фасетов по разделу.
- **Выдача без перезагрузки:** товары, пагинация, сортировка и «Найдено N» обновляются на месте, адрес страницы
  меняется, кнопки «Назад» и «Вперед» работают. Без JavaScript фильтр работает обычными ссылками.
- **Телефон:** панель в шторке, кнопка «Фильтр (N)», внизу «Показать N товаров».
- **«Все фильтры»:** редкие фасеты под кнопкой — списком, слоем или окном.
- **Сортировка «Популярные»:** по продажам за период или по просмотрам.
- **Группировка выдачи** по модели, артикулу или другому полю: размеры одного товара — одной карточкой.
- **SEO:** посадочные страницы с ЧПУ, своими title, H1, описанием и текстом; SEO-шаблоны, которые сами создают
  посадочные для нужных сочетаний; остальные адреса фильтра закрыты от индекса и ведут canonical на раздел;
  карта сайта посадочных (и поставщик для модуля PS Sitemap).
- **Доступность витрины:** WCAG 2.2 AA — управление с клавиатуры, видимый фокус, объявление результатов,
  крупные зоны нажатия на телефоне.
- **Оформление на стороне темы:** переменные CSS `--psf-*`, классы, события `psf:*`, переопределяемые шаблоны
  в папке темы.

## Совместимость

OpenCart 3.0.x / 4.x.

- OpenCart 3.0.x — архив `ps_filter-v<версия>-oc3.ocmod.zip`, PHP 7.4–8.4.
- OpenCart 4.x (проверено на 4.1.0.4) — архив `ps_filter.ocmod.zip` (имя файла менять нельзя: OpenCart 4 берет из
  него код расширения), PHP 8.1–8.5. Возможности те же.
- MySQL 5.7+ или MariaDB 10.3+.

## Установка

### OpenCart 3

1. «Расширения → Установка расширений» — загрузите `ps_filter-v<версия>-oc3.ocmod.zip` (модификаторы обновлять
   не нужно: модуль встраивается событиями).
2. «Расширения → Модули» — у «PS Filter: фильтр товаров» нажмите «Установить». Модуль создаст таблицы,
   события и права; пункт меню — «Каталог → PS Filter».
3. «Каталог → PS Filter → Индексация» — запустите полную переиндексацию.
4. «Дизайн → Макеты» — поставьте модуль «PS Filter» в колонку макетов «Категория», «Производитель» и «Поиск»
   (или выведите панель в шаблоне темы переменной `{{ ps_filter }}`).

Обновление в OpenCart 3 — загрузить новый архив поверх: данные модуля сохраняются, схема обновляется сама при
первом заходе в админку.

### OpenCart 4

1. «Расширения → Установщик» — загрузите `ps_filter.ocmod.zip` и нажмите «Установить».
2. «Расширения → Модули» — у «PS Filter: фильтр товаров» нажмите «Установить»; пункт меню — «Каталог → PS Filter».
3. «Каталог → PS Filter → Индексация» — полная переиндексация; «Дизайн → Макеты» — модуль в колонку макетов
   «Категория» и «Поиск». Чтобы панель была и на странице производителя, в макет «Производитель» добавьте маршрут
   `product/manufacturer.info` (в OpenCart 4.1.0.4 макет привязан только к `product/manufacturer`).

**Обновление в OpenCart 4.** Поверх установленного OpenCart 4 пакет не ставит, поэтому: «Расширения → Модули» —
удалить PS Filter, «Расширения → Установщик» — удалить пакет, загрузить и установить новый, снова установить модуль.
Фасеты, посадочные, SEO-шаблоны, индекс, настройки и место панели в макетах сохраняются (настройка «При удалении
модуля сохранять данные», включена по умолчанию).

## Настройка

- «Каталог → PS Filter → Настройки»: вид панели, шторка, автоприменение, SEO, сортировка «Популярные»,
  группировка, наличие.
- «Фасеты»: какие фасеты и где показывать, порядок, вид (галочки, ползунок, цвета, картинки).
- «Посадочные» и «SEO-шаблоны»: страницы фильтра для поиска.
- «Индексация»: ключ и задания cron (`reconcile` раз в час, `prices` и `warm` ночью, `gc` раз в сутки),
  полная переиндексация.

## Удаление

«Расширения → Модули» → «PS Filter» → «Удалить». В OpenCart 3 (и в OpenCart 4 со снятой галочкой «При удалении
модуля сохранять данные») модуль удаляет свои таблицы (индекс, фасеты, посадочные, SEO-шаблоны, кеш), события,
права, настройки и место в макетах; таблица Manticore, если была, тоже удаляется. Товары, характеристики и опции
магазина не меняются.
